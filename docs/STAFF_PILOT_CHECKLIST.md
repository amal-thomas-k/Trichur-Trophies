# Controlled pilot checklist

Use synthetic entries first, then one small real order after obtaining the normal customer authorisation to process their photographs. Record operator, date, device/browser, printer/driver and results. Software evidence is in `TEST_REPORT.md`; none of the boxes below is automatically passed by a generated PDF.

## Before inviting customers

- [ ] Read reference inventory and verify the selected template is explicitly synthetic or has a completed staff-prepared original master.
- [ ] Have a Malayalam reader check conjuncts, chillus, vowel signs, initials, mixed scripts and long names in enlarged canonical proofs.
- [ ] Verify no legacy-font substitution or stale recipient content remains in an original-derived template.
- [ ] Print calibration at 100% / Actual Size, measure both axes and record printer/media settings.
- [ ] Trial-cut and fit each component in the real trophy; record the validated model/profile calibration.
- [ ] Confirm current backups and perform a restored-instance proof/export download.
- [ ] Configure a reachable HTTPS hostname, private staff credentials and persistent storage.

## Real-device/customer trial

- [ ] Ordinary Android Chrome: photo-first, name-first, copy/paste from WhatsApp, app switching, reload and reconnect.
- [ ] Ordinary iPhone Safari: the same steps plus HEIC acceptance or the specific JPEG/PNG conversion path.
- [ ] First-time user: completes an entry without learning layout or print settings.
- [ ] Older user: can read labels, use touch controls and inspect the enlarged photo/name proof.
- [ ] Confirm fresh entry has no previous person's name/photo/crop, and sorting preserves pairing.
- [ ] Disconnect while uploading: local versus server saved states remain truthful, retry does not duplicate the person.
- [ ] Two helpers add separate entries; one cannot edit the other's work or another order.
- [ ] Correct a name/photo after approval and verify the approval/output is invalidated.

## Print and assembly

- [ ] Inspect skin tones, colour/black appearance, effective photo resolution and edges on actual production media.
- [ ] Compare approved proof with printed piece; measure size and test fit.
- [ ] Reconcile recipient, copy and component counts with the manifest; pair front/base by identifiers.
- [ ] Deliberately reprint one selected component and confirm no whole-order duplicate is generated.
- [ ] Record release and actual physical printing separately.
- [ ] Log time spent and observed errors; do not infer percentage savings from one trial.

Only mark the installation ready for a controlled customer pilot after its software gates and the relevant checks above pass. Broader production readiness requires printer and real-customer evidence.
