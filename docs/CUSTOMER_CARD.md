# Add names and photographs / പേരും ഫോട്ടോയും ചേർക്കുക

1. Open the private order link from the shop. / കടയിൽ നിന്നുള്ള സ്വകാര്യ ഓർഡർ ലിങ്ക് തുറക്കുക.
2. Select a photo from Gallery or Files. If it is only in WhatsApp, save it to your phone first. / ഗാലറിയിൽ നിന്നോ ഫയലുകളിൽ നിന്നോ ഫോട്ടോ തിരഞ്ഞെടുക്കുക. WhatsApp-ൽ മാത്രമാണെങ്കിൽ ആദ്യം ഫോണിൽ സേവ് ചെയ്യുക.
3. Paste or type the recipient's name. Check that the visible photograph belongs to that name. / സ്വീകർത്താവിന്റെ പേര് പേസ്റ്റ് ചെയ്യുക അല്ലെങ്കിൽ ടൈപ്പ് ചെയ്യുക. കാണുന്ന ഫോട്ടോയും പേരും ഒരാളുടേതാണെന്ന് പരിശോധിക്കുക.
4. Save and add the next person. / സേവ് ചെയ്ത് അടുത്ത വ്യക്തിയെ ചേർക്കുക.
5. Open each print proof, enlarge it and check the name, photo and wording. / ഓരോ പ്രിന്റ് പ്രൂഫും തുറന്ന് വലുതാക്കി പേരും ഫോട്ടോയും എഴുത്തും പരിശോധിക്കുക.
6. The organiser approves the final wording and quantities after all proofs are checked. / എല്ലാ പ്രൂഫുകളും പരിശോധിച്ചശേഷം സംഘാടകൻ അന്തിമ എഴുത്തും എണ്ണവും അംഗീകരിക്കുക.

**Saved on this phone** means the work may still need to upload. Wait for **Saved to order** before relying on the shop having it. / **ഈ ഫോണിൽ സേവ് ചെയ്തു** എന്നത് അപ്‌ലോഡ് ബാക്കിയുണ്ടാകാം എന്നർത്ഥമാണ്. കടയിൽ ലഭിച്ചതായി കരുതുന്നതിന് മുമ്പ് **ഓർഡറിൽ സേവ് ചെയ്തു** എന്ന് കാണുന്നത് വരെ കാത്തിരിക്കുക.

Keep the link private. Do not clear browser data while you have unsent work. If an upload fails, reconnect and retry; your saved text need not be typed again. / ലിങ്ക് സ്വകാര്യമായി സൂക്ഷിക്കുക. അയയ്ക്കാത്ത വിവരങ്ങൾ ഉള്ളപ്പോൾ ബ്രൗസർ ഡാറ്റ നീക്കം ചെയ്യരുത്. അപ്‌ലോഡ് പരാജയപ്പെട്ടാൽ ഇന്റർനെറ്റ് ബന്ധം പരിശോധിച്ച് വീണ്ടും ശ്രമിക്കുക.

Staff should have a Malayalam reader validate this instruction card and the application strings before the first customer pilot.
