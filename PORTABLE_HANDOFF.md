# Portable hosting handoff

This source package retains runnable source, prepared runtime artwork, bundled fonts/licenses and synthetic verification evidence. Machine-specific paths and private LAN addresses in prose/reports were replaced with `<PROJECT_ROOT>`, `<TEMP_DIR>`, `<USER_HOME>`, `<WORKSPACE>` and `<SHOP_LAN_IP>`. Substitute your own paths/address when following commands. The master build specification is included byte-for-byte unchanged. Report measurements and pass/failure results were retained; no deployment, phone test or physical calibration is implied. The JSON report list is explicit. All selected text was scanned for credential patterns before packaging.

The supplied derived shop-model master is required by the current migration. It is intentionally included for this private project; originals, live databases, order credentials and Work1 exports are excluded. A private repository does not confer an open-source license.
